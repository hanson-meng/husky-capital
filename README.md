# Husky Capital

The website of Husky Capital, the student investment society of Gould Academy, Bethel, Maine.

Single self-contained page: `index.html`. No build step, no dependencies. Open the file or serve the folder.

The stock tape in the hero shows illustrative quotes by default. To make it live, paste a free key from https://finnhub.io into `FINNHUB_KEY` near the bottom of `index.html`.
